# Haoyu Shen

My research focuses on tidal dissipation and orbital evolution in stellar binaries. I work with Python, C++, and MESA stellar evolution models.

## Selected projects

- **POET for massive stars.** I added an algorithm that reads mixing information from the MESA stellar mesh and finds the boundaries of the convective core, radiative shell, and convective envelope. It uses the core and envelope moments of inertia to determine how POET's two-zone model groups the radiative shell. [Upstream code](https://github.com/kpenev/poet/tree/master) · [Merged pull request #59](https://github.com/kpenev/poet/pull/59)
- **Three-zone tidal dissipation in POET.** I extended POET's C++ solver and Python interface so dissipation can be configured separately for the convective envelope, radiative shell, and convective core. The repository includes an equal-mass binary example. [Code and README](https://github.com/kpenev/poet/tree/poetTrippleZoneDissipation) · [Open pull request #60](https://github.com/kpenev/poet/pull/60)
- **Dynamic Bayesian inference for Kepler binaries.** I developed a tidal-dissipation inference pipeline that retains correlations in the Windemuth et al. joint-prior samples and runs dynesty's dynamic nested sampling. The pipeline supports parallel likelihood evaluation on Slurm clusters, checkpoint recovery, and stopping when posterior CDF uncertainty meets the chosen criterion. [Code and README](https://github.com/kpenev/CircularizationDissipationConstraints/tree/DynamicSamplingForMoreMassiveStars) · [Open pull request #15](https://github.com/kpenev/CircularizationDissipationConstraints/pull/15)
- **Gaia binary inference with Gaussian input distributions.** I built an adapter that turns measured binary parameters and uncertainties into Gaussian distributions for tidal-dissipation inference. It combines stellar-model support checks with the parallel dynamic-sampling pipeline. The package source is published separately from the research data and sampling outputs. [Code and README](https://github.com/kpenev/CircularizationDissipationConstraints/tree/DynamicSamplingForMoreMassiveStarsForGaiaWithGuassianDistributionBuilder) · [Open pull request #14](https://github.com/kpenev/CircularizationDissipationConstraints/pull/14)
